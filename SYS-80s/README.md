# SYS-80s CPU Karte


MC CP/M Computer kompatible CPU Karte zur MC-Computer SYS-1 Karte.

Die SYS-80s Karte hat eine serielle Schnittstelle on Board und benötigt daher zum Betrieb keine  OUT-Karte wie ursprünglich im MC-CP/M Computer vorgesehen.

Es gibt ein angepasstes Monitor Eprom (Mon80V1.bin) um diese Schnittstelle als Console zu nutzen. Die SYS-80s kann auch mit dem originalen Monitor benutzt werden dann ist die Console zur OUT Karte umgeleitet und die "on Board" Schnittstelle frei.

Es ist somit auch möglich die SYS-80s CPU Karte als 1:1 Ersatz für eine alte SYS-1 zu verwenden wenn diese defekt sein sollte.
