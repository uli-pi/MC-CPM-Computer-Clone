# 3 1/2" Floppy-Adapter

Adapter zum Anschließen von 3 1/2" PC-Laufwerken an den Floppy-Controller des MC-CPM-Clones.
Dabei werden die 4 Drive-Select-Leitungen vom Controller in die MOTOR_ON A/B und DRIVE SELECT A/B Leitungen des Laufwerks angepasst.
